CodSoft Artificial Intelligence Internship

Project Description

This project is a simple rule-based chatbot developed using Python. It interacts with users and provides predefined responses based on the input messages.

Features

- Responds to greetings such as Hello, Hi and Hey.
- Introduces itself when asked for its name.
- Responds to How are you questions.
- Provides help instructions.
- Ends the conversation when the user types Bye or Exit.

Technologies Used

- Python 3
- Random module

How to Run

1. Install Python 3.
2. Download the chatbot.py file.
3. Open the terminal in the project folder.
4. Run the following command:

python chatbot.py

Output

The chatbot accepts user messages and displays appropriate predefined responses.
