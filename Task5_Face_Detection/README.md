Task 5 – Face Detection System

Project Description

This project is a Face Detection System developed using Python and OpenCV. It detects human faces in an input image and highlights them using green bounding boxes.

Technologies Used

- Python
- OpenCV
- NumPy

Features

- Detects faces in images.
- Displays detected faces with green bounding boxes.
- Counts the total number of detected faces.
- Saves the output image.

How to Run

1. Install the required libraries:
   "pip install opencv-python numpy"
2. Run the Python file:
   "python face_detection.py"
3. Enter the image path when prompted.

Output

The system successfully detects faces and displays a green bounding box around each detected face.

Conclusion

This project demonstrates basic face detection using Python and OpenCV.
