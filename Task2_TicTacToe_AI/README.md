Project Description

This project is a Tic-Tac-Toe game developed using Python and Artificial Intelligence. The player competes against an AI opponent. The AI uses the Minimax Algorithm to make intelligent moves and try to win the game.

Technologies Used

- Python
- Minimax Algorithm
- Artificial Intelligence

Features

- Human vs AI gameplay
- Intelligent AI opponent
- Minimax Algorithm for decision-making
- Detects win, lose, and draw conditions
- Validates player inputs

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Run the following command:

python tic_tac_toe.py
