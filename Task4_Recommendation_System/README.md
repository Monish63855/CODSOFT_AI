# Task 4 - Recommendation System

## CodSoft Artificial Intelligence Internship

### Project Description
This project is a Movie Recommendation System developed using Python. It recommends movies to users based on their selected movie using Content-Based Filtering.

### Technologies Used
- Python
- Content-Based Filtering
- Difflib
- Movie Dataset

### Features
- Displays available movies
- Accepts user movie preferences
- Recommends similar movies
- Provides multiple movie suggestions
- Supports repeated recommendations
- Handles invalid movie names

### How to Run

1. Install Python.
2. Download the project.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python recommendation_system.py
```

### Sample Input
Inception

### Sample Output
1. Interstellar
2. Avengers
3. Jurassic Park
4. Avatar
